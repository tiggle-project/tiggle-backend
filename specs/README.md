# specs

팀원 모두가 구현의 기준으로 사용하는 공용 명세를 관리합니다. M0에서 팀이 함께 초안을 작성할 예정입니다.

## 들어갈 내용

- **API 명세(OpenAPI):** 노션 API 명세서를 옮겨 와 이곳을 원본으로 삼습니다. 각자의 springdoc-openapi 출력과 이 명세가 일치하는지 확인합니다.
- **이벤트 스키마:** 이벤트 봉투(버전, 이벤트 ID)와 이벤트별 스키마, 버전 정책입니다.
- **예약 상태 전이도:** 좌석, 예약, 결제, 회차의 상태와 전이 조건입니다. 초안은 [`docs/feature-spec.md`](../docs/feature-spec.md)의 "상태 흐름"에 있습니다.

## 변경 규칙

이곳을 바꾸면 모든 팀원의 구현에 영향을 줍니다. 변경 PR을 누가 확인한 뒤 머지할지는 [협업 규칙](../README.md#협업-규칙)과 함께 팀 논의로 정할 예정입니다.
