# loadtest

팀원 모두가 자기 구현을 같은 조건으로 측정하기 위한 공용 도구를 관리합니다.

## 들어갈 내용

- **불변식 검사기(BENCH-03, M2):** "확정 예약 수가 좌석 수를 넘지 않는다", "확정 예약이 유실되지 않는다"를 DB와 Redis를 비교해 검사합니다.
- **k6 시나리오(BENCH-02, M4):** 1) 핫 좌석 동시 선점, 2) 분산 좌석 선점, 3) 선점부터 결제와 확정까지의 전체 흐름입니다.
- **측정 자동화(BENCH-04, M4):** `make bench` 한 번으로 데이터 초기화, 워밍업, 3회 반복, 결과 저장까지 수행합니다.

측정 결과(JSON, Grafana 스냅샷)는 이곳이 아니라 각자의 폴더에 저장하고, 실험 기록은 [`docs/templates/experiment.md`](../docs/templates/experiment.md) 형식으로 작성해 주세요.

## 변경 규칙

시나리오나 검사 기준을 바꾸면 이전 측정 결과와 비교할 수 없게 됩니다. 변경 PR을 누가 확인한 뒤 머지할지는 [협업 규칙](../README.md#협업-규칙)과 함께 팀 논의로 정할 예정입니다.
